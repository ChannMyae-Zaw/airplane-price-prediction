# ✈️ Airplane Price Prediction Website

A machine learning–powered web application that predicts airplane ticket prices based on user input.  
The app is designed with a simple, responsive interface to make price prediction fast and intuitive.

🌐 **Live Demo:** [Airplane Price Predictor]([https://your-deployment-link.com](https://indian-flight-price-prediction-r66m.onrender.com))  

---

## 🚀 Features
- Enter flight details (airline, source, destination, duration, stops, etc.)  
- Get instant predictions powered by a trained ML model  
- Responsive, Bootstrap-based design for smooth usage  
- Deployed online for easy access  

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, Bootstrap  
- **Backend:** Flask (Python)  
- **ML Model:** Scikit-learn (regression-based)  
- **Deployment:** (Heroku / Render / HuggingFace Spaces — update accordingly)  

---

## 📊 Dataset
- Source: [Kaggle Airline Price Dataset](https://www.kaggle.com) (or the dataset you used)  
- Features include:
  - Airline  
  - Date of Journey  
  - Source & Destination  
  - Duration  
  - Total Stops  
- Target: **Ticket Price**
